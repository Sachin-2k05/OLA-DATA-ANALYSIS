

# OLA Data Analysis Dashboard

An interactive **Power BI dashboard** built to analyze OLA ride booking data. The project provides insights into booking trends, revenue, ride cancellations, customer behavior, and overall business performance using data visualization and analytics.

## Project Overview

This project analyzes OLA booking data to help stakeholders monitor key business metrics and identify trends affecting ride operations. The dashboard enables users to interactively explore booking performance, cancellations, revenue, and ride volumes over time.

---

## Objectives

- Analyze overall ride booking performance.
- Track booking success and cancellation trends.
- Monitor total booking value.
- Identify booking patterns over time.
- Build an interactive dashboard for business reporting.
- Support data-driven decision making through visual analytics.

## Key Insights

- Successfully completed rides contribute to the majority of total bookings.
- Driver cancellations represent a significant percentage of unsuccessful rides.
- Ride demand remains relatively stable throughout the month with minor daily fluctuations.
- Interactive filters allow analysis across different time periods.
- Business KPIs can be monitored in real time using dashboard visualizations.
